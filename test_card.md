# Test card — step 1 local agent

Say these six things, in this order, both runs. Same words both times.

1. Say nothing. Let it greet you. Count five seconds of silence after it stops.
2. "I want to book an appointment."
3. "My number is nine eight four zero one seven six five two three."
4. "I need to come in tomorrow because I have a lot of pain on the left side
    and it started two days ago."   (one breath, do not stop in the middle)
5. "What times do you have free tomorrow?"
    Then, WHILE it is still answering, cut in with: "Actually, make it next week."
6. "Okay, thank you, goodbye."

Then Ctrl+C.

## Run A — clear
Slow. Separate every word. In line 3 leave a small gap between each digit,
the way you would when a human is writing it down.

## Run B — natural
Normal speed, the way you would actually talk on the phone. Do not
over-pronounce. Line 3 runs together as one string of digits.

## Prediction, written before the run
Run A fragments MORE than run B. The VAD ends a turn after 0.2s of silence,
so the pauses that make you clearer to a human are exactly what cuts you off.
If that happens, the finding is: speaking clearly breaks this agent.
